# Apple Silicon workshop baseline

Inspected the student setup, embedded build and flash wrappers, native host build,
programmer integration, viewer, package/release scripts, tests, active CMake and Windows
bootstrap plans, and component ownership rules on the workshop Mac. The machine is arm64
Darwin 25.5.0 with CMake 4.3.0 and Ninja 1.13.2. MCUXpresso IDE 25.6.136 and SEGGER J-Link
are installed. PowerShell and Rust were not globally installed, and no matching USB board
was attached during the baseline.

Downloaded PowerShell 7.6.3 into `/tmp` without changing global configuration and ran the
unchanged `src/embedded/build.ps1 -Clean`. It discovered MCUXpresso Arm GCC 14.2.1,
completed all 87 Ninja steps, checked 84 C compile commands for the competition flag
contract, and published `out/artifacts/embedded/nxp_cup_core0.axf` and `.bin`. The AXF is
4,891,004 bytes with SHA-256
`ff47bfab73eb6e3f68a007215c3ecbe4a31c48148050019e7cff5cc4fbfb7b36`; the BIN is
357,104 bytes with SHA-256
`be41ecc5085d71f804bfa3d61eb61a293c75805b899a137d8bac340c63ec6811`.

Installed Rust/Cargo 1.96.1 under `/tmp`, cloned NXP `rblhost`, checked out the repository's
pinned v0.2.0 source commit `7a775dde2c44bd345a1ac067698afa999bd71be0`, and ran
`cargo build --locked --release`. The build completed in about 21 seconds. The 2.8 MB
result is a thin arm64 Mach-O, reports `rblhost 0.2.0`, and links IOKit, CoreFoundation,
AppKit, libiconv, and libSystem only. Its local SHA-256 is
`d75babe663d783ad83a5c5b760ef0581080227031f8d74256fc282d3d2c76344`. This is build
evidence, not a frozen release hash or board proof.

Running `src/host/build.ps1` under the isolated PowerShell fails at line 21 because
`ProgramFiles(x86)` is absent. Source inspection then identified the deeper platform work:
Win32 SetupAPI/HID/registry/serial code in `nxpc_host_core.cpp`; Win32 subprocess,
timeout, BCrypt, temporary-path, and executable-path code in `nxpc_programmer.cpp`;
Windows common-dialog and executable-path code in `nxpc_viewer.cpp`; and Windows-only
libraries, SDL2 package artifacts, file names, manifests, and payload validation in CMake
and the package/release scripts.

The baseline leaves the source tree clean apart from this new plan and its log. No board
flash, runtime CDC session, viewer frame, code signing, notarization, or GitHub publication
was attempted.
