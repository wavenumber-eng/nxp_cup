# Apple Silicon setup and local toolchain checkpoint

Added the thin root `setup.sh` bootstrap. It requires Darwin arm64, recovers the standard
Apple Silicon Homebrew prefix, installs the Homebrew PowerShell formula only when needed,
and delegates every argument and the exit status to the repository-relative shared
`setup.ps1`. It contains no archive pins, checksums, staging, or component build logic and
works from a checkout path containing spaces.

Pinned Arm's official Apple Silicon 14.2.Rel1 `arm-none-eabi` tar.xz. The official archive
SHA-256 is
`c7c78ffab9bebfce91d99d3c24da6bf4b81c01e16cf551eb2ff9f25b9e0a3818`; the extracted
arm64 GCC 14.2.1 SHA-256 is
`07bfe9e74cfe028af639bf38703b2259c608aedee6ff991752084a10b82da614`.
Shared setup now validates safe tar/ZIP paths, preserves Mac ZIP executable modes, has a
30-minute download cancellation boundary, stages and rolls back installs under `out`,
uses Homebrew for missing CMake/Ninja, validates minimum tool versions, and keeps all
Windows pins and winget behavior.

The real 135 MB archive was downloaded despite intermittent CDN stalls, verified, cached,
installed, and then reinstalled from the supplied local archive with no network access.
A normal rerun skipped the already hash-verified compiler. A clean competition build used
the compiler under this checkout's `out/toolchains` for every command, completed all 87
steps and 84 compile-flag checks, and reproduced the known 357,104-byte BIN SHA-256
`be41ecc5085d71f804bfa3d61eb61a293c75805b899a137d8bac340c63ec6811` without using
MCUXpresso.

Six new Mac setup contract tests pass, including delegation from a path with spaces and
explicit rejection of an unpinned Mac runtime. Package automation passes two-run
determinism, manifest hashes, modes, signatures, architecture and native subprocess
capture/output/timeout bounds; the opt-in complete Mac release dry-run also passes.

This setup step intentionally remains active. The production Mac core-tools entry is
marked unavailable rather than inventing a URL, clean commit, checksum, Developer ID
identity, or notarization result. Finalizing that one pin requires an authorized clean
commit and actual immutable signed/notarized GitHub release; ordinary Mac setup currently
requires explicit `-SkipCoreTools`, while the locally built host tools remain usable.
