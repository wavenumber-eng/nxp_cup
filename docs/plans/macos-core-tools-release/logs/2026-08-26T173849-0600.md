# Native macOS viewer app

Built `NXP Cup Viewer.app` as a thin arm64 app with bundle identifier
`com.wavenumber.nxpc.viewer` and minimum macOS 13. The app includes its own pinned
`rblhost` under `Contents/Resources/bin`, resolves that executable relative to the
viewer, and provides an AppKit/UniformTypeIdentifiers firmware picker while retaining
the shared Dear ImGui presentation and programming workflow.

Vendored the official SDL 2.26.5 source archive from libsdl.org with SHA-256
`AD8FEA3DA1BE64C83C45B1D363A6B4BA8FD60F5BDE3B23EC73855709EC5EABF7` and release
tag commit `ac13ca9ab691e13e8eebe9684740ddcb0d716203`. CMake verifies and extracts the
7.7 MB archive under `out`, builds SDL statically, and leaves the viewer linked only to
macOS system frameworks and libraries.

The app's hardware smoke test received 112 frames in five seconds with zero malformed
packets, and a subsequent macOS-13 rebuild received 65 frames in three seconds. The app
launched successfully through LaunchServices. A local ad-hoc hardened-runtime signature
passed strict deep verification; it is explicitly not notarized and is not publication
evidence.

The app executable and CLI declare macOS 13.0 minimum; the imported rblhost declares
macOS 11.0. Native programming uses the same full-readback implementation already proven
on the attached board.
