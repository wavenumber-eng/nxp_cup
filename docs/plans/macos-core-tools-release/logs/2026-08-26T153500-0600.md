# macOS release contract frozen

Frozen the first release to Apple Silicon arm64 and macOS 13 or newer. Intel and universal
binaries are excluded until compatible hardware can supply clean-machine, launch, viewer,
and board evidence. The Mac artifacts use a separate immutable
`core-tools-macos-v<version>` release line so the verified Windows v1.0.1 asset remains
unchanged.

The archive contains a normal `NXP Cup Viewer.app` with bundle identifier
`com.wavenumber.nxpc.viewer`, top-level `nxpc_tool` and `rblhost` executables, and complete
licenses, README, schema-2 manifest, and hashes. The app also carries its own rblhost under
`Contents/Resources/bin` so it remains functional after being moved. SDL2 is statically
built from the pinned repository source; no non-system dylib may remain.

Developer ID Application signing, hardened runtime, and successful notarization are
mandatory for publication. Credentials remain external. Local dry runs may use ad-hoc
signing, must record that they are not notarized, and cannot publish. The release path keeps
the existing clean-commit, immutable-tag, draft verification, anonymous download, and
outer-checksum gates.

The Mac setup owns a thin `setup.sh` bootstrap and downloads the official pinned Arm GNU
14.2.Rel1 darwin-arm64 archive into `out/toolchains`; clean acceptance forbids reliance on
MCUXpresso or a global Arm compiler.
