# Deterministic macOS core-tools package

Extended the existing host package entry point to produce
`nxp-cup-core-tools-macos-arm64-0.1.0.zip` without changing the Windows payload
contract. The Mac archive contains the arm64 `NXP Cup Viewer.app`, top-level
`nxpc_tool` and pinned `rblhost`, the app-private programmer, README, and all three
required license notices. Executable Unix modes, sorted entry names, and fixed ZIP
timestamps are retained.

The schema-2 manifest records macOS arm64, minimum macOS 13.0, bundle identifier
`com.wavenumber.nxpc.viewer`, ad-hoc hardened-runtime signing with notarization false,
source state, AppleClang/CMake/Ninja versions, exact rblhost source/Rust/binary
provenance, pinned SDL source provenance and linkage, and SHA-256 plus size for every
regular payload file. The matching outer checksum file validates successfully.

Two complete staging, ad-hoc signing, manifest, and ZIP runs produced the identical
archive SHA-256
`f10bffff56c1686e226743e553cd42f724d4df68d3475035fad9dba2bdf3d388`.
Extraction preserved execute permissions. Manifest coverage and all eleven recorded
payload hashes passed, strict deep app signature verification passed, and all Mach-O
payloads were arm64. The app and CLI declare macOS 13.0 and have only system dynamic
dependencies; SDL is static.

From the extracted archive, `nxpc_tool selftest` and the embedded `rblhost --version`
passed. With the attached FRDM-MCXN947 running the competition image, the extracted
viewer completed a two-second hidden hardware run with one connection, 41 camera
frames, and zero malformed packets. Local ad-hoc signing remains dry-run evidence only;
Developer ID signing and Apple notarization are enforced by the following release-flow
step before publication.
