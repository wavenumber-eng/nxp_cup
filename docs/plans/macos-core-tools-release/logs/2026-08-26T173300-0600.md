# Host platform boundaries

Kept AVCU parsing, bounded records, control exchange, firmware validation, programming
stages, and UI behavior shared while adding explicit Windows/macOS implementations for
serial and HID discovery, serial I/O, bounded subprocess execution, SHA-256, executable
discovery, environment paths, temporary readback paths, and the native firmware picker.

The shared CLI sources compile with AppleClang 17 under `-Wall -Wextra -Wpedantic
-Werror`. The repository CMake project now selects Windows libraries and payload names or
the macOS IOKit/CoreFoundation frameworks and arm64 rblhost payload without weakening the
existing Windows branch. A tool-only configuration avoids making the SDL viewer a hidden
dependency of the CLI build.

Bench-free `nxpc_tool selftest` passes in the CMake-built Release executable. Windows
runtime regression remains part of the plan exit criteria and has not been claimed from
this Mac.
